# Sample Test Project

A sample Node.js project demonstrating testing with Jest.

## Features

This project includes:
- Simple calculator module with basic arithmetic operations
- String utility functions (capitalize, reverse, palindrome check)
- Comprehensive test suite with 100% code coverage
- Jest testing framework configuration

## Installation

```bash
npm install
```

## Running Tests

```bash
# Run all tests
npm test

# Run tests in watch mode
npm run test:watch

# Run tests with coverage report
npm run test:coverage
```

## Project Structure

```
Sample/
```
