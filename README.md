# Sample Test Project

A simple Node.js test project demonstrating basic project structure, utility functions, and testing with Jest.

## Features

- Basic utility functions (add, multiply, greet)
- Comprehensive test coverage using Jest
- Clean project structure
- Well-documented code

## Project Structure

```
.
├── src/
│   ├── index.js    # Main application entry point
│   └── utils.js    # Utility functions
├── __tests__/
│   ├── index.test.js   # Tests for main application
│   └── utils.test.js   # Tests for utility functions
├── package.json
└── README.md
```

## Installation

```bash
npm install
```

## Usage

Run the application:

```bash
npm start
```

## Testing

Run tests:

```bash
npm test
```
